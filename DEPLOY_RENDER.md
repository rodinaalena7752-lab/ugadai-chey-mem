# Бесплатная публикация на Render

1. Создайте приватный репозиторий на GitHub и загрузите **содержимое** папки `meme-party` в корень репозитория (package.json и render.yaml должны быть в корне).
2. Зарегистрируйтесь на https://dashboard.render.com и свяжите свой GitHub.
3. Выберите New → Web Service → ваш репозиторий.
4. Runtime: Node, Instance Type: Free, Build Command: `npm install`, Start Command: `npm start`.
5. Нажмите Deploy Web Service. После успешного запуска Render выдаст адрес `https://...onrender.com`.
6. Проверьте с трёх телефонов создание комнаты, загрузку мемов, голосование и раскрытие.

Важное ограничение: сервер использует `data/rooms.json` и папку `data/uploads`. На бесплатном Render эти данные **не сохраняются** после перезапуска, засыпания или нового деплоя. Для загрузки мемов за несколько дней нужен внешний сервис хранения и изменение серверного кода. На текущем этапе используйте сайт только для короткой тестовой игры и загружайте изображения непосредственно перед ней.

Не добавляйте в репозиторий персональные изображения и папку `data`.
