# Угадай, чей мем? 🎭

Веб-игра для компании из **3–5 человек**. Один ведущий создаёт комнату и выводит карточки на общий экран; все голосуют с телефонов. Работает с JPG, PNG, WebP и анимированными GIF.

## Запуск

Нужен Node.js 20+ и подключение к интернету для однократной установки пакетов.

```bash
npm install
npm start
```

После запуска откройте `http://localhost:3000`. Для подключения телефонов **в той же Wi-Fi сети** откройте `http://IP-КОМПЬЮТЕРА:3000` (узнайте локальный IP компьютера). Разрешите Node.js входящие подключения в межсетевом экране, если потребуется.

Для доступа из интернета разместите проект на Node.js-хостинге с поддержкой WebSocket (например, Render/Railway или VPS). Стартовая команда `npm start`, переменная `PORT` задаётся хостингом. Важно: для сохранности загруженных мемов между перезапусками нужен **постоянный диск** с переменной `DATA_DIR` указывающей на него; без такого диска данные могут пропадать при перезапусках/деплоях. На одном серверном экземпляре поддерживаются живые комнаты; горизонтальное масштабирование не предусмотрено.

## Сценарий

1. Ведущий создаёт комнату, отправляет ссылку друзьям.
2. Каждый заходит со своим ником и загружает 1–10 картинок/GIF (максимум 6 МБ каждая).
3. Ведущий по желанию загружает отдельные **мемы-подставы**, поставив галочку «Эти файлы — подстава».
4. Ведущий включает дополнительные режимы и запускает игру.
5. Каждый раунд на общем экране появляется мем. С телефона можно выбрать владельца или вариант «Никто из нас». Ведущий может переключить раунд в режим «Кто бы это сохранил?» (это сбрасывает голоса текущего раунда).
6. Ведущий раскрывает ответ, зачитывает результаты и переходит дальше.

## Режимы и очки

- **Угадай владельца**: +2 за правильный ответ, 0 за неправильный. Голосовать за собственный мем нельзя.
- **Мемный самозванец**: ведущий заранее загружает *специальные* подставные мемы. За ответ «Никто из нас» на такой карточке +2.
- **Кто бы это сохранил?**: голосование за наиболее подходящего участника. Это весёлый неоцениваемый раунд: результаты показываются, очки не начисляются.
- **Анонимный позор**: при раскрытии настоящий автор объясняет, зачем сохранил мем (по желанию); не влияет на очки.
- **Ставка на уверенность**: при правильном ответе +4 вместо +2, при неправильном −1 (счёт не уходит ниже нуля).
- **Награда за незаметность**: автор обычного мема получает +1 за каждый неправильный голос другого участника в режиме «Угадай владельца».

## Ограничения v1

- Не предусмотрено удаление мемов, кик игроков, перезапуск той же комнаты или история партий.
- Данные комнат и изображения лежат **на сервере**, а не в браузере. Любой, кто знает ссылку/код, может присоединиться до начала игры. Не загружайте персональные или конфиденциальные фото.
- Автоматическая модерация изображений не предусмотрена.
- Режим общего экрана открывается отдельной вкладкой на устройстве ведущего. Не используйте там голосование; открывайте обычную вкладку для управления.
- Незавершённая игра после рестарта сервера восстанавливается на экране раскрытия, чтобы никто не потерял очки.
